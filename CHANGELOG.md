# Changelog

## 2026-08-28 — v1.2.0 (revision resubmission cut)

- **Model**: HPV `transm2f` default 3.69 → 2.0 with per-act beta clipped to [0, 1] (fixes NaN transmission at high beta scalars). Interventions default `sex='f'` and ablation/excision clear `precin` (`ce2edb19`).
- **Screening**: education-correlated screening now targets an aggregate 70% coverage at an odds ratio of 3 (`SCREEN_EDU_OR = 3`, `SCREEN_CORRELATED_POST ≈ 0.7725`, `SCREEN_CORRELATED_PRE ≈ 0.5309`), replacing the earlier 90/50 (OR ≈ 9) placeholder. `_or5` suffixes now refer only to the vaccination edu_OR.
- **Ensemble**: production run uses 10 top calibration draws × 5 seeds = 50 replicates per scenario, 10 000 agents (was 20 000; halved after 2026-08-28 OOM crash), across all 18 scenarios.
- **Runner**: `run_scenarios.py` refactored to a subprocess-per-scenario orchestrator with resume support (`--scenario`, `--aggregate`, `--n-agents`, `--n-workers`). Fresh Python process per scenario avoids fork-parent bloat that killed the earlier in-process loop.
- **Outputs**: only `results/fig_data/fig{2,3,4,5}_data.csv` are tracked (median + q25 + q75 across replicates). Per-scenario `raw_results/partials/*.csv` are transient and deleted after aggregation.
- **Figures**: main + supplementary figures now include uncertainty (IQR bands on time series, IQR whiskers on bars, paired-diff whiskers on averted bars, per-cell IQR ranges on the Fig 5 heatmap).
- **Supplement**: figS4 renumbered to figS3 (there was no S3). Table S1 (parameter table) generated by `plot_table_pars.py`.
- **Repo**: `figures/v3/` flattened to `figures/`; `archive/` and `run_degree.py` deleted (available in git history).
- Moved manuscript and reviewer comments to `docs/` (from 2026-04-27 v1.1.0 revision milestone).

- Added `.gitignore` excluding large binaries (`vs.msim`, full calibration objects, raw per-event CSVs).
